# Media

This folder is intentionally empty of images at the journal's first draft stage. The game's low-poly production art, animations and visual effects are not final, and publishing stock renders or fabricated 'gameplay screenshots' would misrepresent its current appearance.

When authentic media is ready, it can include dated **in-game screenshots**, **work-in-progress clips**, **concept art explicitly labeled as concept**, and clear gameplay diagrams. Each should identify what it actually represents.

For now, read the [visual direction](../visual-direction/art-and-animation.md) and [gameplay scenarios](../scenarios/README.md).
