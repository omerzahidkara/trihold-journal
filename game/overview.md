# Game overview

**Trihold** is the current *development codename* for a stylized low-poly science-fiction real-time strategy project with browser-oriented multiplayer ambitions. It is not the final game title.

The starting point is deliberately approachable: one main spendable currency, **Credits**, a home Base, fixed-value Mine sites and Outposts that extend the area in which structures can be built. The economy leads directly into territorial defense.

## The opening problem

A natural first strategy is to construct nearby Mines with infantry support, assemble a Sergeant-led squad and expand with an Outpost toward more valuable resources. But the player can instead invest in Recon infantry that search the map for field rewards. Recon can bring Credits, Command Points and information, with the danger of being discovered and hunted.

## The first military problem

Scout Cars are expensive, limited and powerful in the current Base 1 battlefield. They can threaten exposed infantry, fight, carry soldiers and help rescue the wounded. They can also bring infantry to attack an Outpost, but the Outpost's own fire makes leaving the car nearby dangerous.

A successful capture can be undermined by the loss of the transport or a timely counterattack. The question is not only whether you can take ground but whether you can **keep** it.

## What changes later

Base 1 is the early-game foundation, not the entire combat design. Future Base levels are intended to introduce specialist infantry, different vehicles, better anti-vehicle options, additional strategic uses for Command Points and heavy tools for attacking buildings. A tank is envisioned as powerful late-game siege capability. These features are design direction, **not a list of implemented units**.

## Technology and presentation

The development project uses Unity and C#, with a network-authoritative multiplayer foundation and a WebGL-oriented target. Low-poly sci-fi art, animation and effects are unfinished. The game is not publicly released.
